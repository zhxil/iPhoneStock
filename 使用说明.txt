青岛 iPhone 库存助手 · C# / .NET + WinUI 3

双击 IphoneStock.exe，点击“开始监控”。
默认目标：青岛万象城 R557 / iPhone Duo 512GB 星光白色 MK2P4CH/A。
默认查询间隔 60 秒；关闭窗口收进托盘继续运行。右键托盘图标或设置页“退出程序”可停止并退出。
电脑必须联网并保持唤醒。正常打开程序后可手动开始。开启“开机启动并开始监控”并保存后，登录 Windows 自动进入后台监控，不弹主窗口。

有货：Apple 明确返回可取货；无货：Apple 明确返回当前不可取货。
未知：请求被拦截、限流、网络异常、缺失商品、未开售或接口结构变化。未知不等于无货。
遇到 HTTP 541 / 403 冷却 15 分钟；429 至少冷却 2 分钟；手动查询也遵守冷却。
同一城市商品合并查询，不同城市依次查询，每次库存请求至少间隔 60 秒。

提醒：本机托盘通知与提示音，可选 Bark 或飞书推送。系统设置可能关闭通知或静音，请先使用“测试提醒”。
持续有货不重复提醒；离开有货状态后再次有货会重新提醒。提醒不会预留库存，也不会自动下单。
目录为上游项目快照；可添加目录中的其他 iPhone 和中国大陆直营店，实际售卖信息以 Apple 官网为准。

配置与错误日志：%LOCALAPPDATA%\QingdaoIphoneStock
推送地址包含密钥，保存在本机配置中，请勿公开此配置。坏配置会备份且本次运行禁止覆盖。
任务栏状态条默认开启，宽度 108 DIP，显示手机图标与库存状态；下次查询倒计时在监控页查看。单击展开主窗口，右键提供开始/暂停、查询、隐藏与退出。在“设置”中可以关闭状态条。当前适配主屏居中任务栏；左对齐、竖向或无空位时回退托盘。
开机启动仅注册当前 Windows 用户，可在设置中关闭并保存。移动程序目录后需重新保存设置以更新启动路径。当前版本没有自动更新或在线型号目录刷新。

运行包为 Windows x64 自包含文件夹，不需要安装 .NET、Node 或 Rust。请保留完整文件夹，不要单独移动 EXE。
目标系统 Windows 10 2004 或更新版本；未进行干净虚拟机验证。

参考 ENCHIGO/apple-pickup-watcher（66c1da29941ba30cfa7cc13ba1b8f95a65f5f692）的协议与目录，使用 C# 重新实现。

Windows 1.2：左侧原生导航分为监控、添加目标、运行记录；底部设置入口包含查询、开机启动和提醒。小窗口自动切换紧凑导航。

Windows 1.3：监控卡片、添加页和任务栏胶囊显示对应机型及配色商品图。多目标时胶囊优先展示有货目标，否则展示首项。购买页入口位于各商品卡片内。运行记录为分类列表，可搜索、复制当前筛选结果、清空；仅保留本次会话最近 150 条，重启不保留。图片随程序提供，无需反复联网加载。
商品卡片底部“在 Apple 查看”按钮打开对应型号与容量的购买页；右上角“…”菜单可移除目标，需先暂停监控并二次确认。

Windows 1.3.1：显示名称统一为 iPhone库存助手；修复深色模式卡片背景、分隔线与库存文字，支持系统主题实时切换。保留原有配置和启动路径。
