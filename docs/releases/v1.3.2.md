# iPhone库存助手 · Windows 1.3.2 / Android 1.1.1

本版修复 Apple 请求被拦后仍继续查询、重启丢失冷却及 Retry-After 边界问题。更新后仍不能保证绕过 Apple 风控；被拦结果始终显示为“未知”，不会显示成无货。

## 下载

- Windows x64：`iPhoneStock-Windows-x64-v1.3.2.zip`。完整解压后运行 `IphoneStock.exe`，无需另装 .NET。
- Android 8.0+：`iPhoneStock-Android-v1.1.1.apk`。沿用旧版包名与签名，versionCode 提升为 3，可覆盖安装。
- 两端对应源码与 `SHA256SUMS.txt` 随 Release 提供。

Windows 用户请先退出旧程序，再替换完整程序文件夹；保留原路径可继续使用已有开机启动配置。若更改位置，请重新保存开机启动设置。Android 请覆盖安装，不必先卸载。

## 修复

- 两端购物袋暖场返回 403 / 541 / 429 后立即进入冷却，不再追加库存查询；手动重查不能穿透冷却。
- Windows 冷却保存至配置目录的 `request-cooldown.txt`，重启后恢复；记录损坏时保守等待，写入失败时停止本次查询。
- Windows 对异常 Retry-After 做容错解析，长等待分段执行并可取消。
- Android 修复 Retry-After 秒数乘法溢出，不再把超过一天的服务端等待缩短为一天。

详见 [风控检查说明](https://github.com/zhxil/iPhoneStock/blob/main/docs/apple-request-policy.md)。两端同一出口的请求预算仍独立，未提供跨设备协调或代理轮换。

## 验证

- Windows 31 项核心检查通过，自包含发布构建与隔离配置冷启动通过；持久化冷却在界面中生效，原程序配置和暂停状态已恢复。
- Android 24 项库存 JVM 检查、10 项通知参数检查通过，APK v2 / v3 签名及 16KB 对齐检查通过，新旧证书一致。
- AOSP Android 36 模拟器已通过旧版安装→新版覆盖安装、启动与设置页检查，无致命异常；测试期间关闭网络。
- 本次检查不向 Apple 连发请求试探阈值。未完成真实被拦网络恢复、实体小米、长时锁屏或干净 Windows 虚拟机验证。
- 小米超级岛仍未取得 App ID / 官方授权，普通通知可用，不能保证直接上岛。
