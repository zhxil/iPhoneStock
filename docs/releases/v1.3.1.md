# iPhone库存助手 · Windows 1.3.1 / Android 1.1.0

## 下载

- **Windows x64**：下载 `iPhone库存助手-Windows-x64.zip`，完整解压后运行 `IphoneStock.exe`，无需另装 .NET。
- **Android 8.0+**：下载 `iPhone库存助手-Android-v1.1.0.apk`，允许通知后开始监控。沿用上一版签名，可覆盖安装已发布的 1.0 APK。
- `SHA256SUMS.txt` 为本次附件校验值。仓库源码及对应源码附件均保留 GPL 许可与来源声明。

## Windows 1.3.1

- 原生 WinUI 3 导航：监控、添加目标、分类运行记录和设置。
- 对应机型与配色商品图；紧凑任务栏胶囊也使用商品图。
- 购买按钮独立呈现，移除收进更多菜单并二次确认。
- 修复深色卡片背景、分隔线和库存文字，支持系统深浅色实时切换。
- 名称统一为“iPhone库存助手”；保留已有配置目录和开机启动路径。

## Android 1.1.0

- Kotlin + Jetpack Compose / Google Material 3，四页底部导航、动态取色和深浅色。
- 机型与配色图、独立购买入口、分类搜索记录和预测性返回。
- Java 原生库存查询与前台服务，常驻通知和去重到货提醒。
- 小米焦点通知 / 超级岛参数及测试入口已接入；**未取得 App ID 与官方授权，不能保证直接上岛**。普通通知仍可用。

## 验证与已知限制

Windows：21 项核心检查、界面及后台生命周期检查；四页深色→浅色→深色实测通过。Android：27 项 JVM 检查与 AOSP Android 36 模拟器交互验证。未完成实体小米 17 Ultra、长时锁屏、实际重启、干净 Windows 虚拟机及外部推送送达验收。

Android 15+ `dataSync` 服务通常受后台 24 小时合计 6 小时预算限制；停止后需回到应用重新开始。超级岛不延长后台运行预算。

商品目录为内置快照，当前版本不在线更新；库存以 Apple 官网为准，不自动下单、不预留商品。更多界面配图与使用说明见仓库 README。
